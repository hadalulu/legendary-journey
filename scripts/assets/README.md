# Narration sound effects

## `loud-fart-public-domain.wav`

This is a 1.22-second excerpt from **Wet fart + tummy rumbles**, recorded by
Natalie and originally published by PDSounds. The recording was released into
the public domain by its author.

- Source: https://commons.wikimedia.org/wiki/File:Wet_fart_tummy_rumbles.ogg
- License: Public domain
- Changes: excerpted, converted to mono 44.1 kHz PCM WAV, high-pass filtered,
  and loudness-normalized for use in the story narration.
